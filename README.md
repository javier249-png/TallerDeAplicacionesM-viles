# Definición del Proyecto

Aplicación de música orientada al estudio
Plataforma orientada al rendimiento cognitivo que utiliza música con frecuencias que estimulan el aprendizaje (lo-fi, música clásica, ambient).

Audio funcional: Incorpora sonidos binaurales y frecuencias específicas (ondas Alfa o Beta) para inducir un estado de concentración profunda sin distraer el procesamiento de información del cerebro.

Técnicas de gestión del tiempo: Integra un temporizador Pomodoro sincronizado con la música: al pausar o terminar el reloj, el reproductor se detiene automáticamente.

Control del entorno sonoro: Incluye generadores de ruido (blanco, rosa, marrón) y ambientes de fondo (lluvia, viento) para enmascarar ruidos molestos del exterior.

Experiencia de Usuario (UI) Minimalista: Utiliza un feed basado en la interfaz de Spotify, facilitando la familiaridad del usuario y reduciendo la curva de aprendizaje.
